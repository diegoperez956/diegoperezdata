# Site audit, September 12, 2026

Compared against the approved unpublished working tree, not just the last deployed commit.

## Ponytail

- delete: Unused CSS for old metadata labels, tags, back links, and embeds. No replacement. `index.html`
- delete: Speculative image prefetching and its tracking set. Load selected images normally. `index.html`
- delete: Deferred iframe loader that no markup used, numeric/year metadata branches, and unreachable row fallback. No replacement. `index.html`
- native: Anchors and nested button/link rows with custom keyboard handlers. Use buttons for actions and links for navigation. `index.html`

The directory gag, JSON-style project descriptions, and hover previews remain intentional features. No framework, build process, or runtime dependency was added.

## Unslop

Applied [Cursor pstack's Unslop rules](https://github.com/cursor/plugins/tree/main/pstack/skills/unslop).

Removed repeated collection introductions, most `why` descriptions, and vague claims such as "useful, readable, and sharp." Project descriptions name the work and its tools. The two remaining `why` fields explain nonprofit outreach and the subject of the Mexican Revolution poster. Kept the attributed Terry Davis quote and the political artwork.

## Small fixes

Added semantic landmarks, a form label, iframe titles, clickable PDF previews, keyboard focus retention after sorting, and links that respect modified clicks. Muted text now has 5.30:1 contrast against the page background. The folder gag rejects malformed stored records and reserved routes; it works in memory when storage is blocked. Repeated hover no longer reloads the selected preview.
